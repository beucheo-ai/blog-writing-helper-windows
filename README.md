# 블로그 글쓰기 도우미 (네이버 블로그 + aside)

내 블로그 글에서 **나만의 글쓰기 규칙**을 뽑고, 그 규칙대로 키워드 고르기부터 글쓰기, 네이버 에디터 **임시저장**까지 aside가 해 주는 도구예요.
발행 버튼은 직접 눌러요. 이 도구는 임시저장까지만 해요.

부체오(@beucheo.ai)가 만든 도구예요.

## 이 도구가 하는 일

| 하는 일 | 안 하는 일 |
|---|---|
| 내 글을 읽고 내 말투와 서식 규칙 만들기 | 남의 글 문장 가져오기 |
| 키워드 후보 비교 (발행량, 월검색수) | 순위 보장, 조회수 보장 |
| 네이버 자동완성과 상위 글을 aside가 직접 확인 | 가입, 로그인 대신하기 |
| 글 초안 쓰기, 체크, 에디터 임시저장 | 발행, 이웃 관리, 댓글 |

## 준비물

1. **Windows 10/11**
2. **Python 3**: 설치는 `winget install Python.Python.3.12` 또는 python.org에서 받아요. 설치할 때 "Add python.exe to PATH"를 체크해 주세요. 한글이 깨지면 `키워드분석.bat`으로 실행하세요(UTF-8로 자동 설정돼요).
   - `키워드분석.bat`을 더블클릭하면 `.env`가 없을 땐 예시 데이터(데모)로, 있으면 키워드를 입력받아 후보 비교표를 만들어요.
   - 직접 실행하려면 `python -X utf8 도구\seo_analyze.py --demo`
3. **aside**: 이 폴더를 열고 채팅으로 작업을 시킬 앱이에요.
4. **네이버 로그인된 브라우저**: 임시저장할 때 필요해요. 로그인은 직접 해 주세요.
5. **네이버 API 키** (아래 "API 키 준비")

## API 키 준비

키는 미리 발급받아 두어야 해요. 화면 이름은 바뀔 수 있어요.

### 필수: 블로그 검색 API
- 네이버 클라우드의 **NAVER API HUB**에서 Application을 만들고 **블로그 검색** API를 추가해요.
- 인증 정보에서 Client ID와 Client Secret을 확인해요.

### 선택: 검색광고 API (월검색수를 숫자로 보고 싶을 때만)
- 네이버 검색광고의 **도구 > API 사용 관리**에서 고객 ID, 액세스 라이선스, 시크릿 키를 발급받아요.
- **없어도 괜찮아요.** 그러면 월검색수와 경쟁도는 비어 있고, 발행량이 적은 순으로 보여 줘요. 월검색수 대신 aside가 네이버 자동완성과 관련 검색어를 직접 보고 판단해요.

### .env 만들기
1. `.env.example` 파일을 복사해서 이름을 `.env`로 바꿔요.
2. 받은 키를 `=` 뒤에 붙여 넣어요.
3. **`.env`는 절대 공유하지 마세요.** 캡처, 채팅, GitHub 모두 안 돼요. (이 폴더의 `.gitignore`가 GitHub 업로드는 막아 줘요.)

## 처음 한 번 해 볼 것

### 1. 데모로 동작 확인 (키 없어도 돼요)
- `키워드분석.bat`을 더블클릭해요. `.env`가 없으면 예시 데이터로 분석 결과를 보여 줘요.
- 명령 프롬프트나 PowerShell에서는 `python -X utf8 도구\seo_analyze.py --demo`예요.
- 예시 글 `posts/_예시/post.md`로 변환도 해 볼 수 있어요.
  `python 도구\build_html.py posts/_예시/post.md` → 같은 폴더에 `post.html`(미리보기)과 `aside_본문.txt`가 생겨요.

### 2. aside에서 이 폴더 열기
aside에서 이 폴더를 작업 폴더로 열어요.

### 3. 내 규칙 만들기 (처음 한 번)
aside 채팅에 아래를 붙여넣어요. 주소만 내 블로그로 바꿔요.

```
이 폴더의 aside/0_내규칙만들기.md를 처음부터 끝까지 읽고 그 순서대로 해 줘.
나는 A 방식이야. 내 블로그 주소는 https://blog.naver.com/내아이디 야.
```

아직 쓴 글이 없다면 이렇게 보내요.

```
이 폴더의 aside/0_내규칙만들기.md를 처음부터 끝까지 읽고 그 순서대로 해 줘.
나는 B 방식이야. 닮고 싶은 블로그는 아래 주소들이야.
(주소 3~5개)
```

aside가 글을 읽고 분석한 뒤 **질문을 해요.** 쓰기 싫은 표현, 말투, 꼭 넣는 마무리 문구를 솔직하게 답해 주세요. 글만 봐서는 알 수 없는 취향이라서 이 답이 규칙의 품질을 정해요.
샘플 한 단락을 보여 주면 확인하고 OK를 주세요. 그러면 `rules/내규칙.md`가 만들어져요.

> 이 규칙은 **처음 가설**이에요. 첫 글을 쓰고 마음에 안 드는 점을 말하면 규칙을 고쳐 나가요.

## 글 한 편 쓰는 법

aside 채팅에 주제만 적어요.

```
이 폴더의 aside/ASIDE.md대로 이 주제로 블로그 글을 써 줘: (주제)
```

흐름은 이렇게 가요.

| 단계 | aside가 하는 일 | 내가 하는 일 |
|---|---|---|
| 키워드 | 후보 비교, 네이버 자동완성과 상위 글 확인 | 선택 근거를 보고 **OK** |
| 글쓰기 | `post.md` 작성, 체크 | 요약을 보고 **OK** |
| 이미지 (필요할 때만) | 필요한 화면 알려 줌. 이미지 없이 가는 글도 괜찮아요 | 캡처해서 `images/`에 넣기 (개인정보는 가리기) |
| 임시저장 | 에디터에 입력, 개수 확인 | 로그인 |
| 발행 | 하지 않음 | **직접** 확인하고 발행 |
| 성과 분석 (발행 3~7일 뒤) | 키워드별 실제 순위와 통계 정리, 고칠 점 제안 (읽기만 해요) | `aside/4_성과분석.md`를 보고 요청. 통계 캡처를 붙여 주면 정확해요 |

## 내가 쓴 글이나 이미지로 시작하고 싶을 때

주제만 주지 않고 **내가 쓴 초안과 이미지를 바탕으로** 만들 수도 있어요.

1. `posts/` 안에 새 폴더를 만들어요. 예: `posts/20261110_주제`
2. 초안을 `초안.md`로 저장해서 그 폴더에 넣어요.
3. 이미지는 그 폴더의 `images/`에 넣어요. 파일명은 알아볼 수 있게 짓고, 어떤 이미지인지 aside에게 알려 주세요.
4. aside에게 이렇게 보내요.

```
이 폴더의 aside/ASIDE.md대로 posts/20261110_주제 의 초안.md와 images로 블로그 글을 만들어 줘.
```

aside는 초안의 내용과 경험은 그대로 두고, 내 규칙에 맞게 줄바꿈과 구조만 정리해요. 초안에 없는 경험은 지어내지 않고 `[경험 추가 필요]`로 표시해 줘요.

> 채팅 창에 파일을 바로 첨부하는 방식이 되는지는 확인하지 못했어요. 폴더에 파일을 넣고 경로를 알려 주는 방식이 확인된 방법이에요.

## 후기 쓰기 (사진 + 내용 + 레퍼런스)

맛집, 여행, 제품 후기는 이 방식이 편해요.

1. `posts/` 안에 새 폴더를 만들어요. 예: `posts/20261110_성수카페`
2. 사진을 그 폴더의 `images/`에 넣어요. (채팅창에 바로 첨부해도 돼요. aside가 저장해 보고, 안 되면 폴더에 넣어 달라고 알려 줘요.)
3. aside에 이렇게 보내요.

```
이 폴더의 aside/ASIDE.md 후기 모드로 posts/20261110_성수카페 의 사진과 메모로 후기를 써 줘.
내용: (장소, 날짜, 가격, 느낌, 아쉬운 점 등 아는 만큼 대충)
레퍼런스는 (블로그 글 주소 2~3개)야.
```

aside는 레퍼런스에서 **구조와 리듬만** 뽑아 규칙을 만들고(문장은 가져오지 않아요), 사진·내용을 어디에 넣을지 개요를 보여 줘요. OK를 주면 키워드를 고르고 글을 써서 임시저장해요.

- 가격, 동행, 느낌처럼 모르는 사실은 aside가 먼저 물어봐요. 답하지 않은 건 지어내지 않고 `[경험 추가 필요]`로 남겨요.
- 얼굴, 번호판, 영수증의 카드번호가 보이는 사진은 쓰지 않아요.
- 협찬을 받았다면 꼭 알려 주세요. 글 맨 위에 표기를 넣어요.

## 이 폴더 안내

```
README.md            이 안내
키워드분석.bat        더블클릭으로 키워드 후보 비교
.env.example         API 키 양식 (복사해서 .env로)
aside/               aside가 읽는 지침 4개
도구/                파이썬 스크립트 3개
rules/               내 규칙 (처음엔 비어 있어요)
posts/               내가 쓴 글이 쌓이는 곳
```

| 파일 | 설명 |
|---|---|
| `aside/0_내규칙만들기.md` | aside가 내 규칙을 만드는 순서 |
| `aside/ASIDE.md` | aside가 글 한 편을 만드는 순서 |
| `aside/4_성과분석.md` | 발행한 글의 순위와 유입을 aside가 분석하는 순서 |
| `aside/aside_agent.md` | aside가 네이버 에디터에 입력하는 규칙 |
| `rules/내규칙.md` | 내 규칙 (처음엔 없어요. 0단계가 만들어 줘요) |
| `도구/seo_analyze.py` | 키워드 분석 (`--quick`은 후보 비교, `--demo`는 예시) |
| `도구/check_post.py` | 글 체크 (글자 수, 키워드 반복, 서브 키워드 횟수, 태그 누락, 띄어쓰기, 흐름 경고) |
| `도구/build_html.py` | `post.md`를 미리보기와 aside 입력 파일로 변환 |
| `posts/` | 내가 쓴 글이 쌓이는 곳 |

## 꼭 지켜 주세요

- **발행은 직접.** 임시저장까지만 시키고, 읽어 본 뒤 눌러요.
- **하루 1~2개.** 짧은 시간에 많이 올리면 계정에 불리할 수 있어요.
- **내가 해 보지 않은 일은 해 본 것처럼 쓰지 않아요.** 경험 문장은 실제로 있었던 일만 넣어요. aside가 `[경험 추가 필요]`로 표시해 두면 직접 채워요.
- **요금, 한도, 날짜는 직접 확인해요.** aside가 공식 페이지에서 확인한 내용이라도 발행 전에 한 번 더 봐요.
- **다른 블로그 글을 복사하지 않아요.** 레퍼런스는 구조와 리듬만 참고해요.
- **개인정보는 가려요.** 이메일, 이름, 계좌, 주소가 보이는 캡처는 가리고 올려요.
- **키는 비밀이에요.** `.env`를 누구에게도 보내지 마세요.
- 네이버의 약관과 정책은 바뀔 수 있어요. 자동화 도구를 쓰기 전에 직접 확인해 주세요.

## 막힐 때

| 증상 | 확인할 것 |
|---|---|
| `.env에 NCP_HUB_CLIENT_ID ... 이 없습니다` | `.env` 파일 이름과 키 값 확인 (`.env.example`이 아니라 `.env`) |
| `블로그 검색 API 오류` | Application에 **블로그 검색**이 추가됐는지, Client ID/Secret이 맞는지 |
| `.bat`을 열었더니 Python 안내가 나옴 | Python 3를 설치하고 "Add python.exe to PATH"를 체크하세요 |
| 한글이 깨져 보임 | `키워드분석.bat`으로 실행하거나 `python -X utf8`로 실행하세요 |
| 월검색수가 `-`로 나옴 | 검색광고 키가 비어 있어서 정상이에요 (선택 사항) |
| aside가 임시저장 중 멈춤 | 네이버 로그인 상태 확인 |
