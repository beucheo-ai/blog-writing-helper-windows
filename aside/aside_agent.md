# aside 에디터 입력 규칙 (네이버 스마트에디터)

`aside_본문.txt`의 표시를 아래대로 에디터에 입력한다. 표시 글자 자체는 본문에 남기지 않는다.

## 기본 설정
- 글꼴, 크기, 정렬은 `rules/내규칙.md`의 서식을 따른다. 규칙에 없으면 에디터 기본 글꼴, 가운데 정렬로 한다.
- 일반 문장 글자색은 검정(#000000)으로 직접 지정한다. 색을 비워 두면 연하게 보일 수 있다.
- 문장은 고치지 않는다. **파일의 줄바꿈을 그대로** 지킨다. 한 줄은 에디터 한 줄, 빈 줄은 빈 줄이다.

## 표시 처리
| 파일 표시 | 에디터 처리 |
|---|---|
| `제목:` | 제목 칸에 입력 |
| `태그:` | 태그 칸에 쉼표 기준으로 하나씩 입력하고 Enter |
| `[사진 N: 파일명]` | 그 자리에 `images/` 폴더의 같은 이름 사진 업로드 |
| `[소제목] 제목` | 큰 글씨(24)로 굵게 |
| `[소항목] 제목` | 굵게 (크기는 본문과 같게) |
| `**문구**` | 굵게 |
| `==문구==` | 굵게 + 글자 배경색 연노랑(#FFF1A6). 안 되면 가장 가까운 연노랑 |
| `[구분선]` | 구분선 |
| `[표 시작]` ~ `[표 끝]` | 사이의 `\| 칸 \| 칸 \|` 줄마다 한 행. 첫 줄은 머리글(굵게). `\|` 글자는 남기지 않는다 |
| `[소스코드 시작]` ~ `[소스코드 끝]` | 소스코드 블록 하나에 줄바꿈 그대로. 어두운 테마를 고른다 |
| `[번호목록 시작]` ~ `[번호목록 끝]` | 줄마다 번호 목록 항목 하나 (에디터의 번호 목록 기능) |
| `[링크 카드] 주소` | 주소를 한 줄에 붙여넣어 링크 카드가 생기게 한다. 주소가 아니면 건드리지 말고 보고에 적는다 |

## 지킬 것
- **임시저장만 한다. 발행 버튼은 누르지 않는다.**
- 이모지와 스티커를 새로 넣지 않는다.
- 기존 임시저장 글을 덮어쓰지 않고 새 글로 저장한다.
- 저장할 때 "다른 기기에서 수정되었습니다" 창이 뜨면 **[취소]**를 누르고 사용자에게 알린다.
- 네이버 로그인이 필요하면 멈추고 사용자에게 요청한다. 아이디와 비밀번호를 대신 입력하지 않는다.

## 끝나면 이 형식으로 보고
```
임시저장 완료: <제목>
사진 _ / 소제목 _ / 소항목 _ / 표 _ / 소스코드 _ / 형광펜 _ / 굵게 _ / 구분선 _ / 링크카드 _ / 번호목록 _ / 태그 _
색, 스타일을 못 맞춘 곳: <없음 또는 위치>
```
위 숫자를 `도구/build_html.py`가 출력한 "확인 개수"와 비교해서 다르면 어디가 다른지 적는다.
